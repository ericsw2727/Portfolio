# NODEVERSE — 관리자 대시보드 준비

> 문서 상태: 설계 준비. 관리자 대시보드 담당 범위는 확정 전이며, 아래 항목은 구현 성과가 아닌 준비 항목입니다.

## 준비 배경

게임 개발이 진행되는 동안 관리자 대시보드에서 필요한 데이터와 표시 기준을 미리 정리합니다. 실제 기술과 지표는 팀의 요구사항 및 게임에서 수집할 수 있는 데이터를 확인한 후 결정합니다.

## 먼저 정리할 내용

| 항목 | 정리할 질문 | 산출물 |
|---|---|---|
| 사용자와 권한 | 관리자가 전체 사용자를 보는가? 사용자별 상세 화면이 필요한가? | 화면별 조회 범위 |
| 지표 정의 | 무엇을 어떤 기간·단위로 집계하는가? | 지표 정의서 |
| 이벤트 | 게임에서 어떤 동작을 기록할 수 있는가? | 이벤트 명세 |
| 데이터 흐름 | 수집·저장·집계·조회는 어디서 하는가? | 데이터 흐름 설계 |
| 갱신 기준 | 실시간 갱신 또는 일정 주기 집계가 필요한가? | 갱신 주기 및 API 초안 |
| 검증 | 화면 수치가 원본 기록과 일치하는가? | 검증 사례 |

## 지표 정의 양식

| 지표명 | 정의·계산식 | 원천 데이터 | 조회 범위 | 시간 기준 | 갱신 주기 |
|---|---|---|---|---|---|
| 추후 확정 | 추후 확정 | 추후 확정 | 전체 / 사용자별 등 | 기준 시간대·기간 | 추후 확정 |
