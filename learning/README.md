# 학습 기록

개념 설명과 직접 실행한 예제를 함께 정리합니다. 아래 주제는 학습 기록을 쌓을 분류이며, 숙련도나 완료 상태를 뜻하지 않습니다.

| 주제 | 정리할 내용 |
|---|---|
| Python | 데이터 처리, 문법, 알고리즘 |
| SQL | 조회, 집계, 조인, 데이터 정제 |
| Spark | DataFrame 변환, 집계, 분산 처리 |
| Kafka | 이벤트 전달, producer·consumer 흐름 |
| MongoDB | 문서 모델, 집계 파이프라인 |
| Django | 데이터 조회, API, 대시보드 연동 |
