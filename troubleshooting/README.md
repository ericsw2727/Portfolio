# 문제 해결

오류 메시지뿐 아니라 재현 조건과 원인을 확인한 근거를 기록합니다. 현재 등록된 사례는 없습니다.

## 작성 방법

1. [문제 해결 양식](../templates/troubleshooting.md)을 복사합니다.
2. 파일명을 `YYYY-MM-DD-문제명.md`로 지정합니다.
3. 증상 → 재현 → 원인 → 수정 → 재검증 순서로 작성합니다.
4. 해결을 확인한 뒤 아래 목록에 추가합니다.
